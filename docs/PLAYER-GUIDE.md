# 玩家操作指南

这份指南适用于当前的双人多关测试版。两名玩家进入同一房间后，可以移动、瞄准、射击怪物，并在清关后各自选择奖励、确认准备、共同进入下一关。断线恢复和最终结算仍在联调。

## 开局前

先在项目目录启动服务端，再分别打开两个客户端窗口。客户端会自动连接、登录并寻找另一名玩家。看到两个窗口都显示“已连接”“战斗中”，才开始操作。请先用鼠标点一下要控制的窗口，键盘输入只会进入当前有焦点的窗口。

本机手动体验可以在 IDE 的 PowerShell 7 终端执行下面的命令。以下三组分别放在三个终端，服务端启动后保持它的终端打开。若之前已开着旧服务端，先在其终端按 `Ctrl+C`，再启动新的服务端。

```powershell
# 终端一，在 D:\The-Return-of-the-Odyssey 下
. .\scripts\env.ps1
go run ./server/cmd/gameserver -env server/configs/.env

# 终端二，同一项目目录；中文客户端
.\build\client-zh\client\odyssey_client.exe

# 终端三，同一项目目录
.\build\client-zh\client\odyssey_client.exe
```

本次中文玩家版在 `build/client-zh`，窗口标题会显示“奥德赛归途 · 中文测试版”。旧的 `build/client-windows` exe 不会自动更新：它仍显示英文界面，也不能点击奖励卡片。请先关掉两份旧英文客户端，再从 `build/client-zh` 双开；若找不到新文件，请先按 [客户端构建说明](../client/README.md) 构建。

## 一局怎么玩

| 操作 | 会发生什么 |
| --- | --- |
| `W` `A` `S` `D` | 控制自己的角色移动 |
| 移动鼠标 | 把射击方向指向怪物，鼠标位置决定瞄准方向 |
| 按住 `Space` | 持续尝试射击，实际射速由服务端限制 |
| 松开 `Space` | 停止射击 |
| 奖励出现时点击任意卡片，或按主键盘/小键盘 `1` `2` `3` | 选择屏幕上对应的一项奖励；按键前先点游戏窗口以获得焦点 |
| `Enter` | 奖励安装完成后确认下一关准备；两名玩家都确认才会开启下一关 |
| `F3` | 打开或关闭开发诊断信息，正常游玩不需要使用 |
| `Esc` | 退出当前客户端窗口 |

瞄准时把鼠标移到战斗区域里的怪物附近，然后按住 `Space`。判断是否在战斗请看顶部阶段是否为“战斗中”，以及自己的生命值是否大于 0。窗口可拖动边框或最大化，画面会等比例缩放，缩放后鼠标瞄准仍按实际战场位置计算。若这些条件满足、窗口有焦点而射击仍没有反馈，请留下画面截图并告诉开发组，玩家没有额外的攻击按钮可切换。

首关有 8 只敌人。四块发光掩体可以挡住子弹，也会挡住移动；射击时绕到掩体侧面寻找射线。蓝白色弹体和尾迹表示飞行中的子弹，命中时会出现短暂的扩散光圈。

消灭本关全部敌人后，每名玩家点击一张奖励卡片，或按数字键 `1`、`2`、`3` 独立选择。卡片会在鼠标悬停时高亮，选择后显示“正在装备所选奖励”；看到“奖励已装备，按回车准备下一关”后按 `Enter`；两名玩家都准备完成，服务器会自动生成并进入下一关。未及时选择时服务器会应用默认奖励，收到结果后仍需按 `Enter`。

## 看起来卡住了怎么办

| 画面上的情况 | 玩家可以做什么 |
| --- | --- |
| 还在等待第二名玩家 | 再打开一个客户端，确认两边已连接并进入同一房间 |
| 阶段显示“远征失败”，或全队生命值耗尽 | 本局已经结束，不会继续移动或射击。两名队友都在线时，点击“重新开局”或按 `N`。新房间开始后再次查看是否显示“战斗中” |
| 只自己的角色死亡，队友还活着 | 暂时不能操控该角色，等待队友完成战斗或本局结束 |
| 按 `N` 后迟迟没有开始新关卡 | 确认两个客户端都连着服务端。仍未开局时，双方先退出客户端并重新打开两窗口 |
| 显示断线或连接失败 | 等待客户端自动重试，或按 `R` 重新尝试连接。`R` 不会在团灭后重开本局 |
| 窗口连鼠标点击和 `Esc` 都不响应 | 先试窗口右上角关闭按钮。如果 Windows 明确显示“未响应”，最后可以在任务管理器结束该客户端，再重新打开。把当时画面与启动终端里的报错留给开发组 |

新版默认不会显示帧率、网络包和服务器序号等开发信息。需要协助开发组排查时可以按 `F3` 打开诊断面板，再按一次关闭。如果窗口标题仍是英文、找不到“重新开局”，说明打开了旧 exe：退出旧客户端后按上面的中文路径打开新版。若服务端确实是旧版本，也需要先停掉，再按开局命令启动更新后的代码。

两个客户端可以从同一目录启动。诊断日志按进程号分别保存为 `odyssey-client-<PID>.log` 和 `odyssey-client-error-<PID>.log`，不会再因两个窗口争用同一日志文件而触发 Visual C++ 断言。

若新开局后仍无法操作，请留下两个窗口的画面与服务端日志，供开发组排查。
