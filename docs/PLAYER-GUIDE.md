# 玩家操作指南

这份指南适用于双人动态远征版：默认十二关，服务器可用 `ODYSSEY_STAGE_LIMIT` 配置 3–1000 关；客户端显示服务器下发的总关数。每个非最终关卡清关后，两名玩家各自选择奖励、确认准备，共同进入下一关。最终关通关或全队团灭后显示本局团队评分和贡献榜，可由其中一位玩家发起双人重新开局。历史排行榜和断线恢复后的积分补全仍有独立验收范围。

## 开局前

先在项目目录启动服务端，再分别打开两个客户端窗口。客户端会自动连接、登录并寻找另一名玩家。看到两个窗口都显示“已连接”“战斗中”，才开始操作。请先用鼠标点一下要控制的窗口，键盘输入只会进入当前有焦点的窗口。

本机手动体验可以在 IDE 的 PowerShell 7 终端执行下面的命令。以下三组分别放在三个终端，服务端启动后保持它的终端打开。若之前已开着旧服务端，先在其终端按 `Ctrl+C`，再启动新的服务端。

```powershell
# 终端一，在项目根目录下
. .\scripts\env.ps1
go run ./server/cmd/gameserver -env server/configs/.env

# 终端二，同一项目目录；动态远征版客户端
.\build\client-polish-release\client\odyssey_client.exe

# 终端三，同一项目目录
.\build\client-polish-release\client\odyssey_client.exe
```

本次客户端在 `build/client-polish-release`，窗口标题为“奥德赛归途 · 动态远征 · 积分榜”。服务端和两台客户端必须同时升级；旧客户端没有换弹输入，不能配合新服务端正常游玩。旧服务端也不会执行弹药限制或下发导演信息。若找不到新文件，请按 [客户端构建说明](../client/README.md) 构建。

## 一局怎么玩

| 操作 | 会发生什么 |
| --- | --- |
| `W` `A` `S` `D` | 控制自己的角色移动 |
| 移动鼠标 | 把射击方向指向怪物，鼠标位置决定瞄准方向 |
| 按住 `Space` | 持续尝试射击，射速、弹药及装弹状态由服务端限制 |
| 松开 `Space` | 停止射击 |
| `R` | 战斗中手动换弹，耗时 1.5 秒；可以移动但不能射击。仅未连接时才用于重试连接 |
| `Q` | 战斗中使用已装备的治疗药剂；每瓶只能使用一次，满血使用也会消耗 |
| 奖励出现时点击任意卡片，或按主键盘/小键盘 `1` `2` `3` | 选择屏幕上对应的一项奖励；按键前先点游戏窗口以获得焦点 |
| `Enter` | 奖励安装完成后确认下一关准备；两名玩家都确认才会开启下一关 |
| `F3` | 打开或关闭开发诊断信息，正常游玩不需要使用 |
| `F4` | 切换完整 / 简化新增特效；简化时保留伤害数字和命中准星，关闭新增粒子和受伤边框 |
| `Esc` | 退出当前客户端窗口 |
| 胜利后点击“再玩一把”或按 `N` | 两位玩家在线时创建新房间，从第一关重新开始 |

瞄准时把鼠标移到战斗区域里的怪物附近，然后按住 `Space`。判断是否在战斗请看顶部阶段是否为“战斗中”，以及自己的生命值是否大于 0。窗口可拖动边框或最大化，画面会等比例缩放，缩放后鼠标瞄准仍按实际战场位置计算。若这些条件满足、窗口有焦点而射击仍没有反馈，请留下画面截图并告诉开发组，玩家没有额外的攻击按钮可切换。

首关有 8 只敌人。四块发光掩体可以挡住子弹，也会挡住移动；射击时绕到掩体侧面寻找射线。蓝白色弹体和尾迹表示飞行中的子弹，命中时会出现短暂的扩散光圈。

基础弹匣为 12 发，打空后必须按 `R`，不会自动换弹；可提前装弹，满弹匣按 R 不生效，连按不会重新计时。备用弹匣不限量，每关开始补满。武器箱和奖励里的铁制手枪、速射手枪、弹鼓手枪分别将容量改为 16、18、24 发。同槽武器替换、不叠加容量；扩容不会立即赠送子弹，换弹完成后装满新容量。战场右下方显示剩余弹药和换弹进度。

战场左下方显示 AI 导演的实际难度、相对上关变化、上关耗时和队伍剩余生命。导演使用表现驱动规则：清关快且生命充足通常提高压力；耗时长、承伤高或倒地通常降低压力，同时参考伤害输出及装备强度。单次调整限制在 -15% 到 +20%，难度范围 0.5–10；不是固定每关加难。命中闪白、伤害跳字、击杀粒子和准星反馈来自服务器确认的战斗事件，不改变伤害与判定。

每一关开始时，战场会刷新两种共享道具。青色十字是生命补给，受伤时靠近会立即恢复 30 点生命，满血时不会消耗；金色武器箱是新武器，靠近后会自动替换当前武器。两名玩家看到的是同一批道具，任何一人拾取后都会从双方画面消失。当前武器名称显示在战场右上方，拾取成功后会出现中文提示，攻击力则显示在顶部玩家状态栏。

消灭本关全部敌人后，每名玩家点击一张奖励卡片，或按数字键 `1`、`2`、`3` 独立选择。卡片会在鼠标悬停时高亮，选择后显示“正在装备所选奖励”；看到“奖励已装备，按回车准备下一关”后按 `Enter`；两名玩家都准备完成，服务器会自动生成并进入下一关。攻击类奖励会直接改变顶部显示的攻击力，并弹出数值确认；治疗药剂只会装备到身上，不会在选择时立即回血，进入战斗后按 `Q` 才会消耗并恢复生命。未及时选择时服务器会应用默认奖励，收到结果后仍需按 `Enter`。

本局结束后会打开“远征飞行记录”。团队评分由已完成关卡数、全队击杀、用时和倒地次数计算；个人积分由造成伤害、击杀、剩余生命和倒地次数计算。积分使用服务端下发的可靠战斗事件统计，玩家不需要手动提交数据。当前榜单只针对本局，退出客户端后不会保留为历史排名。

## 看起来卡住了怎么办

| 画面上的情况 | 玩家可以做什么 |
| --- | --- |
| 还在等待第二名玩家 | 再打开一个客户端，确认两边已连接并进入同一房间 |
| 阶段显示“远征失败”，或全队生命值耗尽 | 本局已经结束，不会继续移动或射击。两名队友都在线时，点击“重新开局”或按 `N`。新房间开始后再次查看是否显示“战斗中” |
| 最终关清场并显示“远征完成” | 点击“再玩一把”或按 `N`，两位在线队友会一起进入新房间的第一关；其他关卡清场仍须选奖励、按回车准备下一关 |
| 只自己的角色死亡，队友还活着 | 暂时不能操控该角色，等待队友完成战斗或本局结束 |
| 按 `N` 后迟迟没有开始新关卡 | 确认两个客户端都连着服务端。仍未开局时，可以再次尝试；若仍无效，双方退出客户端并重新打开两窗口 |
| 显示断线或连接失败 | 等待客户端自动重试，或按 `R` 重新尝试连接。`R` 不会在团灭后重开本局 |
| 窗口连鼠标点击和 `Esc` 都不响应 | 先试窗口右上角关闭按钮。如果 Windows 明确显示“未响应”，最后可以在任务管理器结束该客户端，再重新打开。把当时画面与启动终端里的报错留给开发组 |

新版默认不会显示帧率、网络包和服务器序号等开发信息。需要协助开发组排查时可以按 `F3` 打开诊断面板，再按一次关闭。如果通关后找不到积分榜或“再玩一把”，请确认打开的是上面 `build/client-scoreboard` 的 exe，并已重启更新后的服务端。

两个客户端可以从同一目录启动。诊断日志按进程号分别保存为 `odyssey-client-<PID>.log` 和 `odyssey-client-error-<PID>.log`，不会再因两个窗口争用同一日志文件而触发 Visual C++ 断言。

若新开局后仍无法操作，请留下两个窗口的画面与服务端日志，供开发组排查。
